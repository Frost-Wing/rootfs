## FrostWing rootfs installation / configuring tool (ext2)

This repository contains the required basic `frost-root` and `frost.py` script to help you cleanly build any one of the following : 

    - Build `disk.img` so virtually you can boot the OS
    - Install the OS root to a disk cleanly.
  
### Usage

For usage refer [Frost-Wing/wiki](https://github.com/Frost-Wing/wiki) for clean structured proper usage of this tool.

Also the [frost.py](./frost.py) is cleanly documented if you do not prefer the OS Wiki.
